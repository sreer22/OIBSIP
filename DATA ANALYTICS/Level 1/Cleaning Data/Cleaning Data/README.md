# Titanic Data Cleaning Project

This project audits and cleans a public Titanic passenger dataset. The source CSV is retained unchanged; the notebook records the observed quality issues, decisions, and validations before exporting a separate cleaned CSV.

## Files

- `Data_Cleaning_Analysis.ipynb` — reproducible quality audit, cleaning, before/after comparison, and export.
- `data/titanic_messy_source.csv` — original downloaded source data.
- `output/titanic_cleaned.csv` — analysis-ready output generated by the notebook.

## Dataset provenance

The source is the public [Data Science Dojo Titanic dataset](https://github.com/datasciencedojo/datasets/blob/master/titanic.csv), a copy of the Kaggle Titanic training dataset. It has 891 records and 12 columns. Inspection found 177 missing ages, 687 missing cabin values, and 2 missing embarkation ports. The data has no exact duplicates; categories are already consistent; it has no date field. These findings are stated as observed rather than manufacturing extra issues.

## Cleaning decisions

- Fill missing ages with the median for the passenger's sex and passenger class.
- Fill the two missing embarkation ports with the observed mode.
- Label missing cabin entries `Unknown` instead of guessing cabins or dropping most rows.
- Remove exact duplicate rows if present; the source currently contains none. Verify passenger ID uniqueness.
- Normalize text whitespace and category case; preserve the original meaning.
- Store `PassengerId` as text, text labels as strings, class/outcome as categories, integer counts as nullable integers, and age/fare as floating-point values.
- Use IQR fences to flag candidates for review, not automatic deletion. Valid high fares, ages, and family counts remain.
- No date conversion is applicable because there is no date column.

## Run

Open `Data_Cleaning_Analysis.ipynb` in Jupyter and run all cells from this directory. Python 3.10+ with pandas, NumPy, Matplotlib, and Seaborn is required. The notebook writes `output/titanic_cleaned.csv` and reloads it to validate the result.

Install dependencies with:

```powershell
python -m pip install -r requirements.txt
```
