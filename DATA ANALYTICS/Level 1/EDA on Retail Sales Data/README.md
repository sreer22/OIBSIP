# Retail Sales EDA

Open and run `Retail_Sales_EDA.ipynb` in Jupyter. The notebook uses the public `retail_sales_dataset.csv` copy in `data/`.

## Source

- Kaggle dataset listing: <https://www.kaggle.com/datasets/mohammadtalib/retail-sales-dataset>
- Downloaded public copy: <https://github.com/romulolacerda/analise-vendas/blob/0e792eb7f9c0d807bc1b247305527ff11b9f73e0/retail_sales_dataset.csv>

The source includes 1,000 transactions, customer age/gender, product category, quantity, price per unit, total amount, and dates from 2023. It does not include item/SKU names, store locations, costs/profit, or a multi-year history; see the notebook's scope notes before interpreting recommendations.
